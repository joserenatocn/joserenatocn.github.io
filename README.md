# 52 Stories

A Jekyll site for logging the Bradbury Challenge, hosted free on GitHub Pages.

## Adding a week

1. On the repo page, click **Add file → Create new file**.
2. Type the name as `_stories/week-01.md` (then `_stories/week-02.md`, and so on). The slash creates the folder.
3. Paste in the contents of `_templates/new-week.md` and fill it in.
4. Click **Commit changes**. The site updates within a minute or two.

## Logging reading

Edit `_data/reading.yml` and copy one of the blocks.

## Changing the title or goal

Edit `_config.yml`.
